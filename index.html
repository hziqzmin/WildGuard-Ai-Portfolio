하지크 (Haziq)

야심찬 풀스택 개발자

저는 기술, 특히 React Native, Spring Boot, Next.js를 활용하여 비즈니스 문제를 해결하는 과정에 매료된 개발자입니다. 경험은 부족하지만 새로운 것을 배우고자 하는 열정이 넘치며 소프트웨어 개발 능력을 향상시키기 위해 끊임없이 노력하고 있습니다.

문제 정의: 연결 단절의 딜레마

야외 활동 애호가들은 종종 휴대폰 통신이 되지 않는 지역으로 모험을 떠나는데, 이는 심각한 안전상의 문제를 야기합니다. 조난, 부상, 장비 고장 등의 비상 상황 발생 시, 이들은 온라인 정보에 접근할 수 없게 되고 기존 앱들은 무용지물이 됩니다. 이로 인해 가장 취약한 상황에서 즉각적이고 신뢰할 수 있는 도움을 받을 수 없게 됩니다.

아키텍처/설계

이 앱은 Jetpack Compose UI를 사용하여 Kotlin으로 완전히 개발된 네이티브 Android 애플리케이션입니다. 핵심 아키텍처는 MediaPipe Framework를 기반으로 구축된 100% 오프라인 검색 증강 생성(RAG) 시스템입니다.

  • MediaPipe Text Embedder가 사용자의 질문을 고차원 벡터로 실시간 변환합니다.
  • 검증된 생존 가이드가 저장된 로컬 데이터베이스에서 코사인 유사도(Cosine Similarity)를 계산하여 질문과 가장 관련된 정보를 즉시 검색(Retrieval)합니다.
  • 검색된 핵심 정보를 프롬프트 컨텍스트에 주입(Injection)하여 AI가 "환각(Hallucination)" 없이 사실에 기반한 답변을 하도록 유도합니다.
  • 완성된 프롬프트는 기기에 내장된 Gemma 3 (Google 최신 경량 모델)에 전달되어 자연스러운 답변을 생성합니다.
  • GPU Delegate 가속을 적용하여, 인터넷 연결 없이도 모바일 CPU/GPU 자원만으로 쾌적한 추론 속도를 보장합니다.

주요 기능 (Key Features)

AI Core

오프라인 RAG 챗봇

인터넷 연결 없이도 작동하는 Gemma 3 (Google) 기반의 온디바이스 AI 챗봇입니다. MediaPipe Framework를 통해 최적화된 파이프라인이 사용자의 자연어 질문을 분석하고, 로컬 DB에서 생존 가이드를 검색(Retrieval)하여 답변을 생성합니다.

  • 평균 응답 속도: 5초 이내 (Galaxy S23 기준)
  • 환각(Hallucination) 방지를 위한 프롬프트 엔지니어링 적용
  • 비행기 모드, 통신 음영 지역에서도 100% 작동

Emergency SOS 툴킷

Native

위급 상황에서 AI보다 더 빠르고 직관적인 대응을 돕는 하드웨어 제어 대시보드입니다. Android Native API를 직접 제어하여 배터리 소모를 최소화하면서도 즉각적인 구조 신호를 보냅니다.

  • CameraManager: 모스 부호 패턴의 고광량 플래시 점멸
  • LocationManager: GPS/GNSS 좌표 즉시 추출 및 시각화
  • MediaPlayer: 최대 볼륨의 고주파 구조 요청 호각 소리 재생
Data

검증된 생존 가이드 (Raw Data)

AI 답변 외에도 사용자가 직접 정보를 탐색할 수 있도록, RAG 시스템에 사용되는 원본 데이터를 읽기 편한 UI로 제공합니다. 응급 처치, 매듭법, 쉘터 구축 등 카테고리별로 정리된 검증된 정보를 제공합니다.

  • JSON 기반의 경량 로컬 데이터베이스 구축
  • 직관적인 카테고리 분류 및 키워드 검색 지원
  • 이미지 및 다이어그램이 포함된 상세 가이드 제공

나의 역할 및 기여

이 프로젝트는 경진대회를 위한 개인 프로젝트였습니다. 유일한 개발자로서 저의 기여는 다음과 같습니다:

  • 제품 및 UI/UX: 전체 제품 비전과 PRD를 수립했습니다. Jetpack Compose와 Material 3를 사용하여 야간 야외 활동 시 눈의 피로를 줄이는 "Responder" 다크 테마를 설계하고 구현했습니다.
  • AI 엔지니어링: MediaPipe LLM Inference API를 활용해 Gemma 3 모델을 Android 앱에 성공적으로 통합했습니다. RAG 시스템을 위한 프롬프트 엔지니어링을 수행하여 답변의 정확도를 높이고 할루시네이션을 최소화했습니다.
  • 데이터 파이프라인: 신뢰할 수 있는 생존 매뉴얼을 수집하고, 모바일 환경의 컨텍스트 윈도우(Context Window) 제한을 고려하여 데이터를 효율적으로 자르는 청킹(Chunking) 및 임베딩 전처리 과정을 수행했습니다.
  • Android 개발: Kotlin Coroutines를 사용하여 무거운 AI 추론 작업을 비동기로 매끄럽게 처리했으며, ViewModel을 통한 UI 상태 관리, 그리고 SOS 기능을 위한 네이티브 하드웨어(Camera, GPS) 제어 로직을 구현했습니다.

결과 및 성과

강력한 생성형 AI 모델(Gemma 3)을 100% 오프라인으로 실행하는 완전한 기능을 갖춘 네이티브 Android 앱을 성공적으로 개발했습니다. 온디바이스 RAG 시스템은 테스트 기기에서 5초 이내에 안전하고 빠르며 유용한 답변을 제공하여 일반 소비자용 하드웨어에서도 복잡한 AI 구현이 가능하다는 것을 입증했습니다. 이 앱은 UI, 상태 관리 및 AI 추론 파이프라인(MediaPipe)을 성공적으로 통합한 안정적인 MVP 버전입니다.

성찰 (배운 점 & 개선할 점)

배운 점

  • RAG는 데이터 전처리가 핵심입니다: AI 모델의 성능은 결국 입력되는 정보의 질에 달려있음을 깨달았습니다. 단순히 문서를 DB에 넣는 것이 아니라, 문맥을 고려하여 데이터를 자르는 '청킹(Chunking)' 전략이 답변의 정확도를 결정짓는 가장 중요한 요소였습니다.
  • 모바일 AI 프레임워크의 효율성: 복잡한 로우 레벨 코딩 없이도 MediaPipe를 통해 Gemma 3 모델을 Android에 빠르게 통합할 수 있었습니다. 이 과정에서 GPU 위임(Delegate) 설정과 메모리 관리가 앱의 반응 속도에 미치는 결정적인 영향을 학습했습니다.
  • 온디바이스 SLM의 실용성 검증: 클라우드 연결 없이도 Gemma 3와 같은 최신 소형 언어 모델(SLM)이 모바일에서 충분히 강력한 추론 능력을 발휘함을 확인했습니다. 이는 오프라인 환경에서도 신뢰할 수 있는 생존 도구를 만들 수 있다는 확신을 주었습니다.

개선할 점

  • AI 모델 및 엔진 최적화: 기존 Mediapipe와 Gemma 모델 조합의 한계를 넘어, 모바일 환경에 더 최적화된 OnnxRuntime과 Phi-3 모델로 마이그레이션하여 추론 속도와 메모리 효율성을 극대화할 계획입니다.
  • 데이터베이스 확장: 현재의 기본 데이터를 넘어, 다양한 기후(극지방, 사막 등)와 응급 상황 시나리오를 포함하도록 임베디드 데이터베이스를 확충하여 RAG 시스템이 답변할 수 있는 범위를 대폭 넓힙니다.
  • RAG 정확도 개선: 문서 청킹(Chunking) 전략을 개선하고 하이브리드 검색을 도입하여, AI가 엉뚱한 답변을 내놓는 환각(Hallucination) 현상을 줄이고 질문 의도에 맞는 정확한 정보를 인출하도록 개선합니다.
  • 로그인 시스템 추가: 사용자별 의료 정보(혈액형, 알레르기)를 안전하게 저장하고, 기기를 변경하더라도 데이터를 유지할 수 있는 로그인 및 동기화 시스템을 구축합니다.
  • 오프라인 지도 기능 추가: GPS 좌표뿐만 아니라 시각적인 지리 정보를 제공하기 위해, 인터넷 연결 없이도 작동하는 벡터 기반 오프라인 지도 기능을 탑재하여 대피소 및 수원지 탐색을 돕습니다.
